# CoreMushroom

La memoria del proyecto vive en **[AGENTS.md](AGENTS.md)**. Este archivo solo
apunta ahí para que no existan dos copias que se desincronicen.

`AGENTS.md` es el nombre que leen la mayoría de las herramientas de asistencia,
no solo una. El proyecto tiene que poder continuarse con cualquiera.

- **[CONTINUAR.md](CONTINUAR.md)** — empieza aquí si acabas de llegar. Estado
  actual, herramientas, comandos de verificación y pendientes por orden.
- **[AGENTS.md](AGENTS.md)** — decisiones tomadas, restricciones duras, reglas
  del código y trampas conocidas.
- **[README.md](README.md)** — cómo usar el tema: despliegue, componentes,
  patterns, campos de lote.

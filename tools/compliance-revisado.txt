# El validador marca cualquier oracion que mencione una palabra vigilada:
# curar, tratar, prevenir, aliviar, dosis, beneficio, efecto y demas. Esas
# palabras no estan prohibidas en si. Lo que no se puede es que aparezcan
# afirmando algo sobre el producto.
#
# Una frase solo pasa si esta escrita aqui, tal cual. Cualquier frase nueva
# que las use falla hasta que alguien la lea y la agregue a proposito, y ese
# cambio se ve en el historial como cualquier otro.
#
# NO agregues una frase aqui solo para que el validador deje de quejarse.
# Lee la frase. Si afirma algo sobre lo que el producto hace, corrige la
# frase, no esta lista.
#
# Las lineas que empiezan con almohadilla son comentarios. La comparacion
# ignora acentos, mayusculas y espacios de mas.

# --- Agregadas al ampliar la lista de terminos vigilados ---------------------
# La lista paso de 25 a mas de 60 terminos porque se podia esquivar cambiando
# un articulo: "mejora tu salud" se marcaba, "mejora la salud" no. Ahora se
# vigila el verbo solo, lo que marca mas frases inocentes. Estas son.

# "Salud" aparece dentro de una negacion sobre datos personales.
En particular, este sitio no solicita ni almacena informacion sobre su estado de salud.

# "Mejorar" se refiere al sitio web, no al producto.
Medir el uso del sitio para mejorarlo.
